# Phase-field applications

The public phase-field surface provides prepared Allen–Cahn, Cahn–Hilliard,
grand-potential, active-storage, adaptive, stochastic, boundary, periodic,
distributed, nonisothermal, anti-trapping, nucleation, mechanical, flow, and
electrostatic contracts with physical accepted-step evidence and native
production-runtime composition. See the
[production guide](../../guides_phase_field.md) and
[coupled multiphysics guide](../../guides_phase_field_multiphysics.md) for
support profiles, qualification evidence, and nonclaims.
