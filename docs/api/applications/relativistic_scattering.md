# Relativistic scattering

::: phydrax.applications.relativistic_scattering

On-shell particle contracts, external states, amplitudes, phase-space maps,
polarization density operations, and weighted events remain separate from the
generic VEGAS integration substrate. Metric signature, frame, mass shell,
spin/color sums, Jacobians, and event measure are explicit. Four-momenta,
`minkowski_dot`, the Minkowski metric, and `LorentzFrame` are core symbols of
`phydrax` ([Special relativity](../phydrax.md#special-relativity)).
