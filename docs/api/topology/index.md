# Computational topology

`phydrax.topology` owns exact invariant analysis, filtrations, persistence, compact
result layouts, and their evidence. `phydrax.discretization` remains the canonical
owner of cell entities, oriented incidence, finite support, cochain spaces, measures,
and Hodge numerics.
