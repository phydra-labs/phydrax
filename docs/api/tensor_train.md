# Tensor trains and quantics

The tensor-train package is a domain-neutral finite-rank representation for discrete
tensors, structured operators, tensorized functions, and bounded alternating solvers. It
does not inherit quantum-state normalization or Hilbert-space semantics.

See [Tensor platform](../guides_tensor_platform.md) for representation, precision,
approximation, resource, and maturity contracts.
