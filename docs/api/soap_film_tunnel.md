# Soap-film tunnel

Quasi-2D gravity-driven soap-film tunnel: constrained Delaunay channel with an
optional circular obstacle, symmetric plug-flow film with inflow, outflow,
wire and rim boundaries, flux and force ledgers, film Mach number and
Strouhal estimation. See the
[soap-film tunnel guide](../guides_soap_film_tunnel.md) for the model,
numerical route, evidence semantics and nonclaims. The film boundary
contracts (`PlugFlowBoundary`, `PlugFlowBoundaryEvidence`,
`PlugFlowBoundaryKind`) render on the
[surface thin-film API page](surface_thin_films.md).
