# Discrete denoising transport

`phydrax.transport.discrete` composes explicit finite-state forward noising with
factor-graph conditional reverse kernels. It is separate from finite-measure optimal
transport and continuous score diffusion: category support, Gibbs state, retained
chain semantics, and layer identity remain explicit.
