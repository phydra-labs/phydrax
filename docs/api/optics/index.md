# Optics

The optics namespace contains explicit geometric, sampled-wave, beamlet, material,
radiative-transport, and stimulated-Brillouin contracts. Rigorous electromagnetic
solvers remain under `phydrax.solver.maxwell`.

- [Geometric optics](geometric.md)
- [Wave optics](wave.md)
- [Optical materials, transport, and SBS](advanced.md)

See the [optics guide](../../guides_optics.md) for model selection and approximation
boundaries.
