# Causal structures

Graph kinds are deliberately non-interchangeable. A DAG may include explicit latent vertices; an ADMG is an observed-variable latent projection; a MAG carries latent and selection semantics; a PDAG makes no completed-equivalence-class claim; a CPDAG represents a DAG equivalence class; and a PAG represents partial ancestral information with provenance.
