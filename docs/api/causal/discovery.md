# Causal discovery

Discovery is host-orchestrated and resource-bounded. CI kernels carry their assumptions and failures. PC-Stable returns a CPDAG only after completion validation. Conservative FCI retains unresolved endpoint circles in a PAG. Bounded GES searches score-equivalence classes exactly within its declared limits.

Discovery results are evidence about an equivalence class, not an SCM or an identification certificate.
