# Diagnostics, qualification, and design

Diagnostics can reject a scoped implication; they cannot validate a causal graph or unmeasured-confounding assumption. Qualification remains conditional on the identification certificate's declared assumptions and still requires reviewed scientific evidence.

Causal intervention candidates compose existing UQ expected-utility and constrained batch-selection contracts. Their condition identity is the intervention regime, never observational conditioning.
