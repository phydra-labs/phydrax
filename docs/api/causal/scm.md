# Structural causal models

SCM construction validates mechanism outputs, exact parent order, numeric revisions, graph acyclicity, and an explicit independent-exogenous declaration. Correlated exogenous laws are outside this execution contract and are rejected. Intervention regimes are immutable descendants of a baseline model. Counterfactual execution requires exact inverse-noise abduction; sampling alone is insufficient.
